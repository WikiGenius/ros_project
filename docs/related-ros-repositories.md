# Related ROS Repositories

This repository is part of a broader ROS and robotics learning portfolio, but it should not be mixed directly into the ROS2 lab repo because it uses a legacy ROS/catkin structure.

| Repo | Stack | Role |
|---|---|---|
| [`ros-husky-traffic-sign-detection`](https://github.com/WikiGenius/ros-husky-traffic-sign-detection) | ROS 1 / catkin | Legacy Husky/Gazebo traffic-sign perception demo. |
| [`ros2-mobile-robotics-labs`](https://github.com/WikiGenius/ros2-mobile-robotics-labs) | ROS2 | Main ROS2 mobile robotics organization hub. |
| [`hello_world_ros2_edx`](https://github.com/WikiGenius/hello_world_ros2_edx) | ROS2 | Course-based ROS2 learning and ROS1-to-ROS2 migration evidence. |
| [`husky-gazebo-image-capture`](https://github.com/WikiGenius/husky-gazebo-image-capture) | ROS2 | Husky image/odometry capture for visual-SLAM dataset preparation. |
| [`ros2-moveit-grasping-demo`](https://github.com/WikiGenius/ros2-moveit-grasping-demo) | ROS2 / MoveIt2 | Perception-guided grasping and manipulation execution evidence. |

Recommended portfolio placement:

- Keep this repo public as legacy perception evidence.
- Use `ros2-mobile-robotics-labs` as the ROS2 organization and learning hub.
- Link between repos through README tables instead of copying code across incompatible ROS stacks.
